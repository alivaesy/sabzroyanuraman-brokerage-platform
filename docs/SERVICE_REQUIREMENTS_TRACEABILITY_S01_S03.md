# ردیابی الزامات S01، S02 و S03

نام خدمات طبق اعلام مالک پروژه: S01 تهیه نقشه؛ S02 درج گواهی اقدام؛ S03 درج ادعای موضوع ماده ۱۰ قانون.

فایل `الزامات_کارگزاری.html` شامل الزامات عمومی شیوه‌نامه و پیوست فنی است؛ در آن مشخصات اختصاصی هر سه خدمت (ورودی‌ها، مدارک، گردش‌کار، API و معیار پذیرش) یافت نشد. ماده ۲ بند «خ» شیوه‌نامه می‌خواهد حداقل سه خدمت مطابق اسناد الزامات خود پیاده و به تأیید معاونت فناوری برسند. بنابراین هیچ قانون تجاری یا مرحله‌ای حدس زده نمی‌شود.
